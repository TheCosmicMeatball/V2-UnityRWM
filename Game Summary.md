Robots Wearing Moustaches - Development Progress SummaryProject OverviewRobots Wearing Moustaches is a multiplayer party game built in Unity using Unity Netcode for GameObjects. The game features a desktop host that leads gameplay (acting as server) and multiple mobile clients connecting to play together giving players controllers to respond in the game.The basic game concept is:Players write creative answers to funny trivia questions,Then the players pick the answer they think is AI and the most chosen answer is eliminated democratically (ties remain not eliminated),Then the players pick the answer they think is CORRECT for points.Points are also awarded for spotting the AI robot during elimination and fooling other players during the multiple choice trivia 3rd phase of each round.There are special rounds: Bonus, Player Questions, Picture Question that follow a similar flow (except for Bonus round which does not have an elimination or voting phase)The most points is shown as % of being human and wins! The lowest points is identified as a robot! :)---Current ArchitectureNetwork ArchitectureUnity Netcode for GameObjects - Multiplayer frameworkDesktop = Host (Server + Client) - Runs the game and manages stateMobile = Clients -
